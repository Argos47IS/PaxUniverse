# Миграция и откат

Эксперимент не изменяет установленный EXE, PCK, patch, профиль пользователя или его партии. Приватная копия запускается из `.local/refactor-game`. QA использует отдельный каталог `%APPDATA%/Pax Universe Refactor QA`.

## Состояние памяти

Игра сохраняет модовое состояние штатным жизненным циклом. Внешний конверт Pax Memory: `version: 1`, `memory: <состояние store>`. Внутренний store также имеет свою версию и список простых JSON-записей; Godot-объекты и callback не сериализуются.

Импорт проверяется до замены активного store. Повреждённые записи, дубликаты ID, конфликтующие подтверждённые факты и неизвестная версия отклоняются атомарно. Неизвестный или повреждённый внешний конверт сохраняется без изменения и не подмешивается в AI. Запись новых данных в этом режиме отключена. Дополнительные неизвестные поля конверта версии 1 сохраняются.

У store есть явно включаемый импорт старого массива. Это API собственной экспериментальной памяти; он не выдаётся за миграцию старых сохранений всей Pax Universe. Автоматического массового преобразования пользовательских партий нет.

## Откат

Выключение `pax_memory` убирает добавление контекста. Адаптер отсоединяет собственные сигналы и восстанавливает исходный callback, только если тот ещё принадлежит ему. Чужую новую обёртку он не перезаписывает. При новом мире журнал и кеш сбрасываются; при загрузке восстанавливается состояние именно этого мира.

Чтобы вернуться к контрольной версии, запустите обычную установленную игру. Экспериментальный профиль и его тестовые партии на неё не влияют.

## Что исправлено в тестовой инфраструктуре

- Пустой PowerShell pipeline давал `disabled: null`; теперь создаётся и проверяется JSON-массив `[]`.
- Новый слот задаётся до создания Main: игровые сервисы привязывают пути сохранения при инициализации.
- Тест ждёт завершения нативного окна итогов через реальные кнопки «Дальше»/«Конец», а не освобождает Main с незавершённой операцией.
- Компактные кнопки HUD проверяются по иконке, подсказке и обработчикам, а не только по непустому `Button.text`.

Эти исправления относятся к нашим тестам, а не объявляются исправлениями игровой симуляции.
