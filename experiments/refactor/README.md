# Эксперимент Pax Universe 0.15.1

Работа ведётся в независимой копии установленной игры. Публичная папка содержит только наши инструменты, тестовые сценарии и документацию. Игра, её ресурсы, лицензия, нативные промпты, сохранения и подробные runtime-дампы сюда не входят.

## Граница доступного изменения

Установленная сборка использует Godot 4.7.2 custom build. Публичная reflection-инспекция нашла 131 игровой скрипт, но ни один не предоставил исходный текст. Поэтому декомпозиция оригинального Main, изменение формул симуляции и замена внутреннего менеджера сохранений не выполняются. Используется разрешённый пользователем модовый путь: отдельный `mods/pax_memory`, работающий через существующий Provider и жизненный цикл PaxMod.

В игре уже есть Provider, память, lorebook и сборка контекста. Наш мод расширяет этот механизм структурированными записями; он не является новой реализацией всей игры или заменой всех AI-вызовов.

## Локальные инструменты

- `tools/prepare_experiment.ps1` создаёт отдельные файлы, проверяет SHA-256 каждого и сохраняет приватный inventory в `.local/Pax Universe Refactor`.
- `tools/audit_host.gd` собирает метаданные средствами Godot без извлечения исходников или обхода защиты.
- `tools/run_experiment.ps1` запускает QA в отдельном пользовательском каталоге. Существующую лицензию можно временно использовать флагом `-UseLocalLicense`; после запуска временная копия удаляется. Пользовательские настройки и партии не копируются.
- `tools/baseline_host.gd` измеряет загрузку мира, интервалы кадров и вызывает проверки. Наличие файла теста не означает его успешное выполнение: результатом служит отчёт вместе с кодом выхода и журналом ошибок.
- `ai_cases.json` содержит наши синтетические задания. Координаты относятся к вымышленной карте, а не к Земле.

## Проверенный результат

Экспериментальный `pax_memory` сохраняет структурированные записи вместе с партией и добавляет ограниченную выдержку к существующему контексту Provider. Полный прогон после изменения: 52 проверки хранилища, 18 адаптера, 48 механики — успешно. Отдельная интеграция с локальной Qwen3.5 4B: 28 из 29 проверок, все три ответа получены; модель прочитала запись памяти и штатным действием перевела камеру на Луну. Одна проверка формата даты не прошла: верная дата написана словами вместо цифр.

Проверены исходные 415 файлов установки — SHA-256 не изменились. Четыре дополнительных прогона производительности прошли, но рост FPS не доказан. Кандидат общих AI-инструкций отклонён: ручная оценка на отложенной выборке дала 1/10 для исходного варианта и 3/10 для кандидата, что недостаточно для выпуска.
