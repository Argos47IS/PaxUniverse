# Совместимость и область проверки

Контроль: Pax Universe 0.15.1 / Godot 4.7.2 custom build, Windows, NVIDIA GeForce RTX 5050 Laptop GPU, viewport 1920×1080, Forward+, штатные VSync и ограничение 30 FPS.

Две визуальные модификации — Earth Atlas 0.2.1 и Pax Interface 0.3.1 — используются без изменения их кода. Pax Memory устанавливается третьим модом только в экспериментальную копию.

Внешний baseline проверяет создание нового мира, доступ к странам и телам, построение окна дипломатии, открытие и закрытие двух игровых окон, течение одного дня, паузу и завершение нативных итогов, добавление персонажа и хроники, штатное сохранение и загрузку в новом Main. Дополнительно проверяются основные элементы трёх вариантов UI. Это не проверка полного прохождения каждой роли.

Память проверяется на двух уровнях: независимый store и реально загруженный адаптер. Для сохранения тест добавляет узнаваемую запись, проверяет её в штатном файле мира, пересоздаёт Main с тем же слотом и ищет запись после загрузки.

## Особенность версии 0.15.1

События `_game_loaded` и `_world_ready` могут передавать разные экземпляры PaxGame для одного Main. Сравнения оболочек по ссылке недостаточно для передачи загруженной памяти. Адаптер должен связывать состояние с живым Main и одновременно не переносить его в другую партию.

JSON хранит числа без GDScript-различия int/float. Тест дискового содержимого сравнивает нормализованные JSON-значения, сохраняя проверку каждого поля; проверка восстановленного store выполняется отдельно.

## Не проверено полностью

- Старые пользовательские кампании из предыдущих версий игры: они не открывались и не преобразовывались.
- Многолетняя устойчивость экономики, полный цикл войны и дипломатического мира, multiplayer.
- Все сторонние моды и будущие версии внутренних полей Provider.
- Размещение точек в провинциях по ответам AI: синтетический replay не доказывает работу камеры или географических координат.

Подтверждение успешного прогона требует одновременно отчёта без проваленных проверок, нулевого кода выхода и отсутствия ошибок Godot. Предупреждения тестового экземпляра о намеренно повреждённых сохранениях ожидаемы и учитываются отдельно.

## Обычный запуск экспериментальной копии

`tools/launch_experiment.ps1 -SmokeTest -UseLocalLicense`: повтор с ожиданием 1200 кадров завершился за 43,084 с, exit 0, без Godot ERROR и предупреждений об утечках. Конфигурация запуска не содержит QA-autoload и использует отдельный профиль. Это проверка запуска и завершения, а не автоматическая проверка всех кнопок меню. Неудачный короткий запуск и его ограничения сохранены в KNOWN_ISSUES.md.
