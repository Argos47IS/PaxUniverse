# Pax Universe — контекст проекта

Общаться по-русски, кратко и конкретно. Сохранять пользовательские изменения.

Перед разработкой модов прочитать docs/modding-notes-ru.md: там сохранены изученные правила, пути, API, ограничения и неточности документации.
Документация разработчика находится в установленной игре в docs/modding/; вход — ru/README.md, API — en/api-reference.md. Необязательная локальная копия docs/modding-reference/ не публикуется в Git.
Обычный путь игры на Windows: %LOCALAPPDATA%/Programs/Pax Universe. Проверять фактический путь перед запуском.
Использовать патчи данных, точные русские идентификаторы, локализацию RU/EN и строгую типизацию GDScript. Читать AGENTS.md конкретного мода. После изменений запускать проверку мода установленной игрой; не выдавать изучение документации за успешный тест.

Все актуальные моды публикуются в Argos47IS/PaxUniverse. Каждый мод хранить отдельно в mods/<id>/; установочные ZIP — в dist/<id>/. Не смешивать ресурсы и манифесты разных модов. Тестовые копии игры, кэши, пользовательские данные и исторический earth_atlas_hd оставлять локально. Прототип pax_units не обозначать как завершённый набор.

С 26.09.2026 пользователь разрешил сразу публиковать каждую переработку и обновление в GitHub вместе с кодом и результатами проверки. После изменения выполнить соразмерную проверку, обновить документацию и отправить изменения в Argos47IS/PaxUniverse; проверить фактический commit удалённой ветки. Непроверенную адаптацию обозначать как незавершённую, не как готовый релиз. Не публиковать лицензии, учётные данные, QA-профили и файлы игры.
