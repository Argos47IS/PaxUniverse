# Pax Universe — моды

Независимые моды для [Pax Universe](https://paxuniverse.ru). У каждого своя папка, `mod.json`, ресурсы и инструкция. Можно устанавливать нужные моды по отдельности.

| Мод | Что меняет | Версия | Статус |
| --- | --- | --- | --- |
| [Земля: Атлас HD](mods/earth_atlas/) | Рельеф и читаемость политической карты Земли | 0.2.1 | Для игры 0.15.1 |
| [Pax Interface](mods/pax_interface/) | HUD, темы, цвет, прозрачность, порядок кнопок, анимации и звук | 0.3.1 | Для игры 0.15.1 |
| [Pax Units](mods/pax_units/) | Новые модели юнитов; первый танк с масштабом по приближению карты | 0.0.1 | Прототип для 0.14.1; ещё не адаптирован к 0.15.1 |
| [Pax Memory](mods/pax_memory/) | Структурированная память для штатного AI-контекста | 0.1.0 | Эксперимент для отдельной копии 0.15.1 |

## Скачать и установить

- **Карта:** [earth_atlas-0.2.1.zip](dist/earth_atlas/earth_atlas-0.2.1.zip).
- **Интерфейс:** [pax_interface-0.3.1.zip](dist/pax_interface/pax_interface-0.3.1.zip).

Откройте ссылку на нужный ZIP и скачайте исходный файл кнопкой **Download raw file**. Папка пользовательских модов Windows: `%APPDATA%\Pax Universe\mods` (точный путь также показывает команда `folders` в F8).

Для установки **папкой** распакуйте ZIP в отдельную подпапку: например, `mods\paxinterface\mod.json` и `mods\paxinterface\main.gd` должны находиться рядом. Карта устанавливается в другую подпапку. Имя папки может отличаться от `id` в `mod.json`; ID менять не нужно. Затем перезапустите игру и включите мод в лаунчере.

Игра также принимает ZIP без распаковки в пользовательской папке модов или в `mods` рядом с `PaxUniverse.exe`.

При обновлении замените старый ZIP: в папках модов игры и пользовательского профиля должна остаться одна копия каждого ID. Старые ZIP в репозитории сохранены для истории, для 0.15.1 скачивайте версии по ссылкам выше.

Для установки из исходников скопируйте только нужную папку из `mods/` в пользовательскую папку модов. Не устанавливайте одновременно папку и ZIP одного мода. ZIP всего этого репозитория не является одним игровым модом.

Если галочка включена, но HUD отсутствует, проверьте `%APPDATA%\Pax Universe\logs\godot.log`. Ошибка `Parse Error` в `pax_interface/main.gd` означает, что код не скомпилировался. При повреждении установки восстановите файлы из исходного ZIP: первая строка `main.gd` должна быть `extends PaxMod`. Пользовательские настройки хранятся отдельно в `mod_settings/pax_interface.json`; удалять их не требуется. [Проверенный случай восстановления папочной установки](docs/interface-folder-recovery-0.15.1.md).

Pax Units пока предназначен для тестирования: реализован танк, весь набор с концепта ещё не создан. Для него нет готового стабильного ZIP. [Что проверено и что ещё предстоит](mods/pax_units/README.md).

Pax Memory испытывается только в отдельной копии и профиле. [Инженерный эксперимент](experiments/refactor/) содержит исходники, проверки с локальной Qwen3.5 4B и [HTML-отчёт с графиками](experiments/refactor/report/report.html). Полная переработка закрытого ядра и рост FPS не заявляются.

## Структура

```text
mods/
  earth_atlas/        # Карта: код, текстуры, локализация
  pax_interface/      # HUD: код, звук, локализация
  pax_units/          # Юниты: модель танка, адаптер, тесты
  pax_memory/         # Эксперимент: структурированная память AI
dist/
  earth_atlas/        # Установочные архивы карты
  pax_interface/      # Установочные архивы HUD
  pax_memory/         # Экспериментальный пакет памяти
experiments/refactor/ # Аудит, стенд, AI-оценка и HTML-отчёт
design/               # Концепты и требования
docs/                 # Наши заметки и отчёты проверок
tools/                # Генераторы ассетов и запуск QA
tests/                # Внешние проверки; не входят в ZIP модов
previews/             # Выбранные снимки проверок
```

Новые моды добавляются отдельной папкой `mods/<id>/`. Общие изменения должны явно указывать, каких модов касаются. Старый ID карты `earth_atlas_hd` сохранён только в истории.

## Проверка

**Earth Atlas 0.2.1 и Pax Interface 0.3.1 адаптированы к Pax Universe 0.15.1** и новой песочнице. Старые версии блокируются при запуске кода. Новый HUD также корректно освобождает старый контейнер при горячей перезагрузке. Настройки модов сохраняются.

[Проверка совместимости 0.15.1](docs/compatibility-0.15.1.md) содержит результаты GPU-тестов и ограничения. Внутренний загрузчик игры всё ещё сравнивает манифесты с **0.13.2**; это не означает поддержку старых сборок без нового API ресурсов.

Предыдущие результаты:

- [Атлас 0.2.0](docs/earth-atlas-020-validation.md).
- [Интерфейс 0.3.0](docs/pax-interface-030-validation.md): 505 проверок.
- [Прототип танка](docs/pax-units-prototype-validation.md): 22 проверки на GPU, три масштаба карты.

Проверка одного мода через F8 в запущенном мире:

```text
check earth_atlas
```

CLI `--check-mods` в 0.15.1 может завершаться с кодом 0 при неактивном загрузчике и не проверять файлы. Нужны фактические ненулевые счётчики файлов и отсутствие ошибок. Внешний QA запускается через `tools/run-compatibility-test.ps1`; он использует отдельный профиль и штатную активацию модов, оставляя песочницу включённой.

Проверка фактически установленных папок с сохранением их имён, в отдельном QA-профиле:

```powershell
./tools/run-compatibility-test.ps1 -Stage interface -FolderModsDirectory "$env:APPDATA/Pax Universe/mods" -UseLocalLicense
```

Тест копирует оба мода в `user://mods` QA-профиля, запускает игру и удаляет временные копии после проверки. Рабочие папки и пользовательские партии не меняются. Без `-FolderModsDirectory` проверяются ZIP из `dist/`.

Для экспортированного `PaxUniverse.exe` не используйте `--path`: в проверенной сборке этот аргумент запрещён. Полная документация разработчика доступна в установленной игре, `docs/modding/`; в репозитории хранятся наши [заметки](docs/modding-notes-ru.md).

## Происхождение ресурсов

Рельеф Атласа основан на **NASA Earth Observatory / GEBCO**; источник, преобразование и контрольные суммы находятся в [elevation-source.json](mods/earth_atlas/textures/elevation-source.json). Цветную текстуру игры мод получает во время запуска. Значки и звуки HUD, а также геометрия танка созданы для этого проекта. Генераторы включены в исходники. Игра и её PCK в репозиторий не входят.
