# Pax Universe — моды

**Улучшенная карта Земли и настраиваемый игровой интерфейс для [Pax Universe](https://paxuniverse.ru).** Earth Atlas и Pax Interface проверены на **версии игры 0.16.2**. Их можно установить вместе или по отдельности; у каждого мода свои код, ресурсы и настройки.

## Скачать актуальные версии

Ссылки в таблице скачивают готовые ZIP напрямую. Для установки не нужно скачивать весь репозиторий или собирать моды из исходников.

| Мод | Что меняет | Версия | Скачать ZIP |
| --- | --- | --- | --- |
| [Земля: Атлас HD](mods/earth_atlas/) | Более выразительный рельеф Земли, читаемая политическая заливка и настройка качества карты | **0.2.1** | **[Скачать Earth Atlas — 13,8 МиБ](https://github.com/Argos47IS/PaxUniverse/raw/refs/heads/main/dist/earth_atlas/earth_atlas-0.2.1.zip)** |
| [Pax Interface](mods/pax_interface/) | Компактный HUD, объёмные кнопки, темы, цвет, прозрачность, перестановка команд, анимации и мягкие звуки | **0.3.2** | **[Скачать Pax Interface — 68,4 КиБ](https://github.com/Argos47IS/PaxUniverse/raw/refs/heads/main/dist/pax_interface/pax_interface-0.3.2.zip)** |

В **Pax Interface 0.3.2** исправлены повторяющиеся ошибки при обработке дополнительных кнопок без связанного окна и конфликт декоративных элементов с перестроением игровых окон. В частности, восстановлено добавление кнопки бестиария Cosmic Expansion; её доступность по прогрессу игры не изменялась. Настройки оформления сохраняются.

**В разработке:** [Pax Units 0.0.1](mods/pax_units/) — прототип новых моделей юнитов. Пока реализован первый танк с масштабированием на карте. Прототип проверялся на 0.14.1, ещё не адаптирован к 0.16.2 и не имеет готового стабильного ZIP.

## Установка

1. Закройте игру и скачайте нужные архивы по ссылкам выше.
2. Откройте папку пользовательских модов Windows:

   ```text
   %APPDATA%\Pax Universe\mods
   ```

3. Положите ZIP в эту папку **без распаковки**. Каждый мод устанавливается отдельным архивом.
4. Откройте лаунчер → **«Моды»**, включите нужные моды и перезапустите игру.

Точный путь также показывает команда `folders` в консоли F8. Каталог `mods` рядом с `PaxUniverse.exe` тоже поддерживается, но хранить один и тот же мод сразу в обоих местах не нужно.

### Обновление уже установленного мода

Если мод установлен из магазина, замените его старый архив новым, сохранив имя:

| Скачанный файл | Имя существующего магазинного архива |
| --- | --- |
| `earth_atlas-0.2.1.zip` | `store_zemlya-atlas-hd.zip` |
| `pax_interface-0.3.2.zip` | `store_pax-interface.zip` |

При обычной ZIP-установке замените предыдущую версию соответствующим новым архивом. **Во всех папках модов должна остаться одна установка каждого ID** (`earth_atlas` и `pax_interface`). Не оставляйте одновременно старый и новый ZIP или папку и ZIP одного мода.

Если мод уже установлен распакованной папкой, обновите файлы внутри неё из нового ZIP. `mod.json` и `main.gd` должны находиться рядом в отдельной подпапке мода. Папку и `id` переименовывать не требуется.

**Не удаляйте `mod_settings` и сохранения:** оформление интерфейса и параметры Атласа хранятся отдельно от архивов. После замены файлов перезапустите игру. Старые ZIP в `dist/` сохранены для истории; для игры 0.16.2 используйте ссылки из таблицы выше.

Если HUD отсутствует при включённой галочке, проверьте `%APPDATA%\Pax Universe\logs\godot.log`. При повреждении файлов восстановите мод из исходного ZIP. [Проверенный случай восстановления папочной установки](docs/interface-folder-recovery-0.15.1.md).

## Структура

```text
mods/
  earth_atlas/        # Карта: код, текстуры, локализация
  pax_interface/      # HUD: код, звук, локализация
  pax_units/          # Юниты: модель танка, адаптер, тесты
dist/
  earth_atlas/        # Установочные архивы карты
  pax_interface/      # Установочные архивы HUD
design/               # Концепты и требования
docs/                 # Наши заметки и отчёты проверок
tools/                # Генераторы ассетов и запуск QA
tests/                # Внешние проверки; не входят в ZIP модов
previews/             # Выбранные снимки проверок
```

Новые моды добавляются отдельной папкой `mods/<id>/`. Общие изменения должны явно указывать, каких модов касаются. История старого ID карты `earth_atlas_hd` не является четвёртым актуальным модом.

## Проверка

**Pax Universe 0.16.2:** Atlas — **71 проверка**, HUD — **505 основных + 45 регрессионных**, повторная загрузка обоих модов — **209 проверок**. Эти прогоны завершены без ошибок движка. В совместном запуске с Cosmic Expansion и Event Banners остаются отдельные ошибки, воспроизводимые без HUD; полностью чистая работа всех сторонних модов не заявляется.

[Подробные результаты и ограничения](docs/compatibility-0.16.2.md) · [HTML-отчёт](docs/compatibility-0.16.2.html) · [Результаты в JSON](docs/compatibility-0.16.2-results.json).

**Earth Atlas 0.2.1 и Pax Interface 0.3.1 адаптированы к Pax Universe 0.15.1** и новой песочнице. Старые версии блокируются при запуске кода. Новый HUD также корректно освобождает старый контейнер при горячей перезагрузке. Настройки модов сохраняются.

[Проверка совместимости 0.15.1](docs/compatibility-0.15.1.md) содержит результаты GPU-тестов и ограничения. Внутренний загрузчик игры всё ещё сравнивает манифесты с **0.13.2**; это не означает поддержку старых сборок без нового API ресурсов.

Предыдущие результаты:

- [Атлас 0.2.0](docs/earth-atlas-020-validation.md).
- [Интерфейс 0.3.0](docs/pax-interface-030-validation.md): 505 проверок.
- [Прототип танка](docs/pax-units-prototype-validation.md): 22 проверки на GPU, три масштаба карты.

Проверка одного мода через F8 в запущенном мире:

```text
check earth_atlas
```

CLI `--check-mods` в 0.15.1 может завершаться с кодом 0 при неактивном загрузчике и не проверять файлы. Нужны фактические ненулевые счётчики файлов и отсутствие ошибок. Внешний QA запускается через `tools/run-compatibility-test.ps1`; он использует отдельный профиль и штатную активацию модов, оставляя песочницу включённой.

Проверка фактически установленных ZIP с сохранением их имён, в отдельном QA-профиле:

```powershell
./tools/run-compatibility-test.ps1 -Stage interface -InstalledModsDirectory "$env:APPDATA/Pax Universe/mods" -UseLocalLicense
```

Тест копирует оба мода в `user://mods` QA-профиля, запускает игру и удаляет временные копии после проверки. Рабочая установка и пользовательские партии не меняются. Для распакованных модов используется `-FolderModsDirectory`; без обоих параметров проверяются ZIP из `dist/`.

Для экспортированного `PaxUniverse.exe` не используйте `--path`: в проверенной сборке этот аргумент запрещён. Полная документация разработчика доступна в установленной игре, `docs/modding/`; в репозитории хранятся наши [заметки](docs/modding-notes-ru.md).

## Происхождение ресурсов

Рельеф Атласа основан на **NASA Earth Observatory / GEBCO**; источник, преобразование и контрольные суммы находятся в [elevation-source.json](mods/earth_atlas/textures/elevation-source.json). Цветную текстуру игры мод получает во время запуска. Значки и звуки HUD, а также геометрия танка созданы для этого проекта. Генераторы включены в исходники. Игра и её PCK в репозиторий не входят.
