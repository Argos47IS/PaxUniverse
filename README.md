# Pax Universe — моды

Три независимых мода для [Pax Universe](https://paxuniverse.ru). У каждого своя папка, `mod.json`, ресурсы и инструкция. Можно устанавливать нужные моды по отдельности.

| Мод | Что меняет | Версия | Статус |
| --- | --- | --- | --- |
| [Земля: Атлас HD](mods/earth_atlas/) | Рельеф и читаемость политической карты Земли | 0.2.0 | Готовый выпуск |
| [Pax Interface](mods/pax_interface/) | HUD, темы, цвет, прозрачность, порядок кнопок, анимации и звук | 0.3.0 | Готовый выпуск |
| [Pax Units](mods/pax_units/) | Новые модели юнитов; первый танк с масштабом по приближению карты | 0.0.1 | Рабочий прототип танка |

## Скачать и установить

- **Карта:** [earth_atlas-0.2.0.zip](dist/earth_atlas/earth_atlas-0.2.0.zip).
- **Интерфейс:** [pax_interface-0.3.0.zip](dist/pax_interface/pax_interface-0.3.0.zip).

Откройте ссылку на нужный ZIP и скачайте исходный файл кнопкой **Download raw file**. Поместите ZIP в папку `mods` рядом с `PaxUniverse.exe`, перезапустите игру и включите мод в лаунчере. Распаковывать архив не требуется.

Для установки из исходников скопируйте только нужную папку из `mods/` в `mods/` игры. Не устанавливайте одновременно папку и ZIP одного мода. ZIP всего этого репозитория не является одним игровым модом.

Pax Units пока предназначен для тестирования: реализован танк, весь набор с концепта ещё не создан. Для него нет готового стабильного ZIP. [Что проверено и что ещё предстоит](mods/pax_units/README.md).

## Структура

```text
mods/
  earth_atlas/        # Карта: код, текстуры, локализация, тесты
  pax_interface/      # HUD: код, звук, локализация, тесты
  pax_units/          # Юниты: модель танка, адаптер, тесты
dist/
  earth_atlas/        # Установочные архивы карты
  pax_interface/      # Установочные архивы HUD
design/               # Концепты и требования
docs/                 # Наши заметки и отчёты проверок
tools/                # Генераторы ассетов и запуск QA
previews/             # Выбранные снимки проверок
```

Новые моды добавляются отдельной папкой `mods/<id>/`. Общие изменения должны явно указывать, каких модов касаются. История старого ID карты `earth_atlas_hd` не является четвёртым актуальным модом.

## Проверка

Последняя проверенная сборка игры сообщает версию данных **0.14.1**. Загрузчик этой сборки сравнивает совместимость с **0.13.2**, что учтено в манифестах.

При подготовке публикации 26.09.2026 установленный файл патча игры обновился после успешных прогонов. Повторный CLI-запуск не смонтировал моды и проверил ноль файлов. Совместимость с этим новым патчем пока не подтверждена; приведённые ниже результаты относятся к предыдущей проверенной сборке.

- [Атлас 0.2.0](docs/earth-atlas-020-validation.md).
- [Интерфейс 0.3.0](docs/pax-interface-030-validation.md): 505 проверок.
- [Прототип танка](docs/pax-units-prototype-validation.md): 22 проверки на GPU, три масштаба карты.

Проверка одного установленного мода:

```powershell
& 'C:\путь\к\Pax Universe\PaxUniverse.exe' --headless -- --check-mods earth_atlas
```

Для экспортированного `PaxUniverse.exe` не используйте `--path`: в проверенной сборке этот аргумент запрещён. Полная документация разработчика доступна в установленной игре, `docs/modding/`; в репозитории хранятся наши [заметки](docs/modding-notes-ru.md).

## Происхождение ресурсов

Рельеф Атласа основан на **NASA Earth Observatory / GEBCO**; источник, преобразование и контрольные суммы находятся в [elevation-source.json](mods/earth_atlas/textures/elevation-source.json). Цветную текстуру игры мод получает во время запуска. Значки и звуки HUD, а также геометрия танка созданы для этого проекта. Генераторы включены в исходники. Игра и её PCK в репозиторий не входят.
