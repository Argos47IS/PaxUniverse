## Что показано

Кнопка «Интерфейс» рядом с инструментами карты открывает правую панель «Настройка интерфейса». На время настройки она занимает место карточки региона.

- Тема и цвет акцента: палитра и выбор собственного цвета.
- Прозрачность фона панелей; подписи и значки сохраняют полную непрозрачность.
- Масштаб интерфейса и размер текста.
- Режим перестановки кнопок с перетаскиванием за ручки.
- Переключатель подписей кнопок.
- Предпросмотр, применение, отмена и сброс.

На макете показаны примерные настройки: тема «Графит», прозрачность 15%, масштаб 100%, обычный текст, включённые подписи. Это предложение по интерфейсу, а не измеренные игровые значения.

## Поведение при будущей реализации

1. Пауза, вход в настройки и выход из режима редактирования остаются доступными при любом расположении кнопок.
2. Перетаскивание включается отдельным режимом, чтобы обычное нажатие случайно не переставляло команды. Порядок хранится по стабильным идентификаторам действий, а не переведённым подписям.
3. Цвета тревог и игровых состояний сохраняют смысл; пользователь меняет оформление и акцент. Для своего цвета нужен достаточный контраст текста и значков.
4. Масштаб и длинные подписи должны укладываться в экран. Если позднее появится скрытие команд, скрытые действия остаются доступными через «Ещё».
5. «Отмена» возвращает оформление, которое было при открытии. «Применить» сохраняет настройки, «Сбросить» возвращает значения по умолчанию в предпросмотре.
6. Настройки и возможные будущие профили оформления сохраняются отдельно от игрового мира. Сохранение и обмен профилями — дополнительная возможность, не отдельный видимый блок этого макета.

Точный запрос генерации: prompt.txt. Исходный одобренный макет сохранён отдельно.

Плавные анимации, подсветка и тихие звуки наведения/нажатия обязательны для будущего мода. Полные требования пользователя и стартовые параметры отклика сохранены в ../interface-requirements-ru.md.
