# Pax Units — первый рабочий танк

2026-09-26. Пользователь спросил о создании моделей по концепту и приемлемом масштабе карты. Подготовлен проверяемый первый образец; полный набор из пяти моделей ещё не реализован. Основная установка игры не менялась.

## Результат

- Оригинальный GLB, воспроизводимый Python-генератор, 13 416 треугольников/5 материалов/11 примитивов. Нет сторонних художественных ассетов.
- Наследник штатного Фигурки3Д заменяет `_танк`; используется документированный PaxMod.model и штатный кадровый pipeline. Исходный SubViewport сохраняется для восстановления; изменяется только привязка поля `Карта.фигурки` и texture отображения.
- Ориентация GLB(-Z) приведена к native(+X). Размер24–36 logical units вместо native16, с промежуточным32 при зуме13. Экипаж отодвинут от корпуса. Счётчики и выбор по ним остаются native.
- Действия при неизвестном renderer ограничены проверкой методов, свойства и загрузки скрипта; это снижает риск после обновления, но внутренний API всё равно нестабилен.

## Итерации и проверка

Первый GPU-прогон15/15 выявил при просмотре светлый материал, неверное направление -Z→+X и перекрытие экипажа увеличенным корпусом. Второй19/19 проверил исправления и автоматическое подключение/переподключение; просмотр выявил необходимость меньшего размера при отдалении. Финальный22/22 добавил изменение размера24/32/36, все проверки прошли. Все три GPU-процесса exit0/stderr0. Рендеры просматривались визуально.

Проверки сцены и выбора выполнялись на настоящей карте игры со специально добавленными тремя визуальными записями отрядов; Main process остановлен в QA, чтобы не перезаписывать fixture из симуляции. Пользовательские партии не загружались. Версия данных игры0.14.1; движок Godot4.7.2, Vulkan, RTX5050 Laptop. Мод совместно загружен с earth_atlas0.2.0 и pax_interface0.3.0.

GLB SHA256: `a66cc4211d6f60196f222fb2c92fa2786688dea59a4762b5d6123f153114e7a2`; проверенная QA-копия совпала с исходником. Артефакты `previews/pax-units/render-final/` содержат `report.json`, журналы, native before, три масштаба after, отдельный реальный рендер GLB. Концепт imagegen находится отдельно в design и не является доказательством визуальной проверки.

## Границы

Финальный штатный `--check-mods pax_units`: 10 файлов/2JSON, 0 ошибок и 0 предупреждений валидатора, exit0. При завершении headless движок отдельно сообщил известные по предыдущим модам 4 ObjectDB/2 resources. Это сообщение не смешивается с результатом GPU-прогона, у которого stderr пуст. Логи: `previews/pax-units/validation-final/`.

Это рабочая процедурная заготовка; нет UV/текстур износа, анимационных клипов и LOD. Сходство с детализированным концептом пока частичное. Массовые скопления, бой, смена мира, работа танковых транспортных маршрутов и глобуса не проверены. Отдельный hitbox на корпусе не реализован. Утверждений об итоговом FPS нет. Прототип не установлен и не выпущен как полный набор юнитов.
