# Совместимость с Pax Universe 0.15.1

Проверка от 26.09.2026. Выпущены и установлены **Earth Atlas 0.2.1** и **Pax Interface 0.3.1**. Автоматическое подключение, функции карты, интерфейс и повторная загрузка проверены в свежем мире на GPU. Финальный повтор полного HUD и усиленная проверка перезагрузки завершились успешно.

## Проверенная сборка

Данные игры `res://data/version.txt` сообщают **0.15.1**, внутренний загрузчик модов — **0.13.2**. Это разные значения: нижняя граница `game_version` в манифесте сама по себе не доказывает совместимость с предыдущими выпусками. Движок — Godot 4.7.2, Vulkan, NVIDIA GeForce RTX 5050 Laptop GPU.

## Изменения модов

Новая песочница проверяет все скрипты пакета до запуска. Прежние моды содержали прямые файловые операции, динамическую загрузку ресурсов и тестовые сценарии с доступом к внутренним скриптам игры. Эти операции теперь блокируются.

- Оба мода используют `load_resource` и другие разрешённые помощники Pax API. Тесты вынесены в `tests/` репозитория и не включаются в установочные ZIP. Ограничения песочницы не отключаются; EXE и PCK игры не изменяются.
- Atlas получает тексты игровых шейдеров через `Pax.text`. Настройки `earth_atlas` сохраняются; импорт прежнего `earth_atlas_hd` возможен только через API уже активного старого мода. Файлы выключенного legacy-мода напрямую не читаются.
- При выгрузке HUD старый корневой контейнер сразу отсоединяется от дерева, затем освобождается. Это предотвращает его повторный захват новым экземпляром интерфейса при F6 и сохраняет корректное восстановление штатных элементов.

В новой игре загрузка кода модов отложена до штатной активации. Одиночный `--check-mods` в неактивированном окружении может вернуть exit 0 и **0 проверенных файлов**. Такой результат не считается успешным тестом. Внешний QA-host вызывает штатный `Pax.включить_моды`, затем настоящий `check`; сканер безопасности остаётся включённым.

Atlas проверен через реальные элементы настроек: включение и восстановление исходных шейдеров, сохранение значений, естественность/политическая заливка/кварталы, отсутствие повторных обработчиков и окон, выгрузка и подключение к существующему миру, Земля → Марс → Земля. Исходные настройки QA восстановлены побайтно. При 1920×1080 качество 50/100/150/200% даёт подложку 960×540 / 1920×1080 / 2880×1620 / 3840×2160; игровой слой управления не растягивается. Реальные текстуры: цвет **8192×4096**, океан **2048×1024**, рельеф **10800×5400**; `use_map = use_ocean = 1`.

HUD проверяет темы, акцент, прозрачность, масштаб, размер текста, подписи и порядок команд, применение/отмену/сброс настроек, анимации, подсветку и звуковой отклик, карту и окна игры, роли страны/человека/организации, адаптацию к размерам окна и восстановление штатного интерфейса. Тест перезагрузки дополнительно выполняет три принудительные перезагрузки через Pax API и отключение/включение каждого мода в том же мире.

Опубликованные [отчёты и скриншоты](../previews/compatibility-0.15.1/) включают автоматическое подключение, все 505 проверок HUD, 71 проверку Atlas и 209 проверок совместной работы. Полные локальные журналы сохранены в `previews/compat-current/` и `previews/compatibility-c48a3f39d29a/`. Воспроизводимый запуск — `tools/run-compatibility-test.ps1`, внешний host — `tools/compatibility_host.gd`; стадии: `automatic`, `validate`, `atlas`, `interface`, `reload`.

```powershell
python tools/package_mods.py
./tools/run-compatibility-test.ps1 -Stage interface -UseLocalLicense
./tools/run-compatibility-test.ps1 -Stage atlas -UseLocalLicense
./tools/run-compatibility-test.ps1 -Stage reload -UseLocalLicense
```

Дополнительный контроль старых ZIP подтвердил `blocked: load` / `blocked: os` для Atlas 0.2.0 и HUD 0.3.0. При этом `Pax.run_command("problems")` возвращал `No problems.` — читать также runtime stderr. Загрузка новых ZIP проходит тот же сканер без блокировок.

## Ограничения и диагностика

Использовался отдельный профиль **Pax Universe Atlas QA**. Для штатной активации временно применена существующая локальная лицензия на том же компьютере; её содержимое и другие секреты не входят в репозиторий или артефакты публикации. Пользовательские сохранения не открывались. Не проверялись длительная симуляция, все сочетания сторонних модов и субъективная комфортность звука вместе с музыкой пользователя. Проверки звука подтверждают воспроизведение, уровни и настройки, но не заменяют прослушивание.

Предварительный внешний тест Atlas завершался с `0xC0000005` без GDScript-ошибки. В тесте найдено сравнение через `Array.has` с уже освобождённым `panel`; проверка перенесена перед освобождением, добавлены поэтапные журналы. После этого получен полный успешный GPU-прогон при неизменённом коде Atlas. Без дампа и независимого воспроизведения точная причина аварии не доказана: диагностика также изменила время выполнения. Это не заявляется как исправление подтверждённого сбоя самого мода.
