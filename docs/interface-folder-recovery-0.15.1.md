# Восстановление папочной установки Pax Interface

Проверено 26.09.2026 на установленной игре **0.15.1**; SHA256 патча: `c48a3f39d29a3063c5b77d1b528292b6f87ced47e21d3ed357534d69309f91c6`.

## Причина и восстановление

Моды находились папками в `%APPDATA%/Pax Universe/mods`: `earthatlas` с ID `earth_atlas` и `paxinterface` с ID `pax_interface`. Оба были включены. Журнал игры содержал `Parse Error: Unexpected identifier "Откройте" in class body` в первой строке `res://mods/pax_interface/main.gd`.

Установленный `main.gd` состоял из строки «Откройте файл слева.» — 37 байт вместо 48 614 байт рабочего файла версии 0.3.1. Когда и чем файл был изменён, не установлено. Сравнение SHA256 всех файлов обнаружило ровно одно отличие у интерфейса и ни одного у Атласа.

Повреждённый файл сохранён в локальную резервную копию и заменён оригиналом 0.3.1. Настройки оформления не изменились, что проверено по контрольной сумме. Версия мода осталась 0.3.1: исправлена установка, изменений кода самого HUD не требовалось. При уже открытой игре нужен перезапуск, чтобы заново загрузить восстановленный скрипт.

## Проверка

`tools/run-compatibility-test.ps1` получил параметр `-FolderModsDirectory`. В этом режиме он берёт реальные установленные папки, сохраняет их физические имена и копирует их в `user://mods` отдельного QA-профиля. ZIP-дубликатов в копии игры нет. Дополнительные файлы и папки модов в QA-каталоге, а также повторные ID во входных папках отклоняются. Исходная установка остаётся нетронутой, временные копии удаляются после теста.

Запуск:

```powershell
./tools/run-compatibility-test.ps1 -Stage interface -FolderModsDirectory "$env:APPDATA/Pax Universe/mods" -UseLocalLicense
```

Результаты:

- Штатная активация и сканер: оба мода загружены; Atlas — 16 записей / 4 JSON, HUD — 23 записи / 3 JSON; **0 ошибок и 0 предупреждений**.
- Автоматическое подключение к свежему миру, оформление HUD и шейдер карты: **11/11**.
- GPU-проверки интерфейса: **505/505**, включая настройки, темы, масштаб, порядок команд, отклик, роли и восстановление штатного интерфейса при выгрузке.
- Код выхода процесса 0, stderr пуст. Снимок игрового кадра просмотрен: верхняя панель, нижние команды и кнопка «Интерфейс» присутствуют.
- Виртуальный путь `res://mods/pax_interface/skin/finish.gd` работает и при физической папке `paxinterface`; переименование не требуется.

Машинные результаты: [активация и валидатор](../previews/folder-installation-0.15.1/automatic-report.json), [505 проверок HUD](../previews/folder-installation-0.15.1/interface-report.json), [расположение тестируемых модов](../previews/folder-installation-0.15.1/installations.json).

Проверялся свежий отдельный мир на копии установленной игры. Пользовательская партия не открывалась, длительная симуляция не проверялась.
