# Земля: Атлас HD

Версия 0.2.1, внутренний ID `earth_atlas`: адаптация к песочнице модов Pax Universe. Внешнее название и оформление карты сохранены.

Визуальный мод для плоской карты современной Земли в Pax Universe.

- Реальная светотень рельефа NASA/GEBCO, 10800×5400.
- Используется цветная текстура игры 8192×4096; искусственного увеличения её разрешения нет.
- Подложка по умолчанию считается в полном разрешении вместо половинного.
- Процедурные кварталы и поля приглушены; поверхность сохраняет природный рисунок.
- Заливки государств спокойнее, контуры провинций и рек сглажены при отображении.
- Климат, затопление, снег, фронты, выделение, туман войны и информационные слои остаются игровыми.

## Использование

Поместите `earth_atlas-0.2.1.zip` в папку `mods` рядом с игрой вместо предыдущего ZIP этого мода. Распаковывать ZIP не требуется. Перезапустите игру и при необходимости включите «Земля: Атлас HD» версии **0.2.1** в лаунчере. Откройте карту Земли. В нижней панели игры появится «Атлас HD» с включением нового вида, качеством 50/100/150/200% и настройками естественных цветов, политической заливки и кварталов.

В 0.13.0 ошибочное автоотключение относится к прежнему ID `earth_atlas_hd`; новая версия использует `earth_atlas`. Галочку новой версии можно включать и выключать обычным способом. Сам код загрузчика игры не изменяется.

По умолчанию: 100%, естественные цвета 80%, заливка 25%, кварталы 8%. Для сравнения отключайте новый вид в окне настроек. При медленном перемещении карты выберите 50%; 150/200% используют supersampling, максимум 4096 пикселей по длинной стороне подложки.

Настройки сохраняются отдельно от партий средствами Pax API. При обновлении с 0.2.0 они сохраняются. Перенос настроек прежнего `earth_atlas_hd` допускается только через API уже активного старого мода; его файлы напрямую не читаются. Уже сохранённые настройки `earth_atlas` имеют приоритет. Если старый мод не активен, новая установка использует свои настройки или значения по умолчанию. Мод не изменяет игровые ресурсы, население, границы владений, сейвы или исходные PCK. Рельеф используется только для освещения, не для расчёта уровня моря. Сглаживание контура — визуальная интерполяция, точность клика остаётся ограничена исходной сеткой провинций.

Мод предназначен для современной карты `earth`. Другие планеты и геологические карты Земли используют исходный вид. Глобус не изменяется.

## Совместимость

Версия 0.2.1 предназначена для **Pax Universe 0.15.1** с новым `PaxMod.load_resource`. Внутренний загрузчик игры всё ещё сравнивает манифесты с версией 0.13.2, поэтому поле `game_version` не выражает фактическую нижнюю границу поддержки этого выпуска.

Прежний мод `earth_atlas_hd` 0.1.1 можно оставить установленным. Если он также загружен, новая версия временно уступает ему карту, чтобы не создавать вторую кнопку и не накладывать эффект дважды. После выгрузки старой версии новая подключается автоматически. Выбор модов в `mods.json` не переписывается, старые файлы не удаляются. Для использования только новой версии можно выключить старую в лаунчере; это не обязательный шаг установки.

Новая песочница проверяет все скрипты внутри модов до запуска. В 0.2.1 загрузка ресурсов и чтение шейдеров используют Pax API, а тестовые сценарии вынесены из устанавливаемого мода. Ограничения песочницы не отключаются. Старый `earth_atlas_hd` 0.1.1 и пакет `earth_atlas` 0.2.0 могут блокироваться самой игрой.

Стабильный Pax API не предоставляет настройки плоской карты, поэтому адаптер проверяет внутренние свойства класса Карта. При изменении структуры/шейдеров после обновления может потребоваться обновление мода. Патчи шейдеров выполняются в памяти; исходные игровые шейдеры и данные целиком в мод не копируются. Другой мод, меняющий те же шейдеры карты, может конфликтовать.

В исходной игре маска океана 2048×1024, сетка провинций 4096×2048. Этот мод не повышает географическую точность этих данных: при сильном приближении детализация берегов и границ ограничена ими. Более высокая настройка качества увеличивает GPU-нагрузку.

## Источник рельефа

NASA Earth Observatory / GEBCO, Blue Marble Next Generation.
https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/topography-bathymetry-maps/
https://www.nasa.gov/nasa-brand-center/images-and-media/

Исходник 21600×10800: 8-bit, 0–6400 м. Числовое усреднение 2×2 создаёт карту 10800×5400; 16-bit хранит дробные средние, не добавляет измерительной точности. Вершины выше 6400 м в источнике насыщены. Происхождение и SHA256 — textures/elevation-source.json. Воспроизводимый скрипт находится в рабочем проекте tools/prepare_elevation.py.

## Проверка

`PaxUniverse.exe --headless -- --check-mods earth_atlas`

Результат валидатора должен содержать ненулевое число проверенных файлов: один только код выхода 0 не доказывает загрузку мода. Исторические сценарии разработки находятся отдельно в `tests/earth_atlas/` репозитория и не входят в ZIP. Прежние флаги `--atlas-…-test` в устанавливаемом моде не выполняются: они использовали доступ, который новая песочница запрещает. Актуальная проверка и её ограничения описываются в отчёте совместимости в `docs/` репозитория.

При разработке очищайте только `mod_cache/earth_atlas.zip` и `earth_atlas.stamp` в тестовом профиле перед сменой версии: проверка свежести игры основана на времени файлов и может пропустить замену одного старым файлом.
