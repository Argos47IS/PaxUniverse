# Pax Units — tank prototype 0.0.1

Первый технический и визуальный образец нового набора юнитов. Создана настоящая оригинальная GLB-модель танка; адаптер заменяет конструктор танков в штатном 3D-слое плоской карты. Счётчики, анимация родного экипажа и выбор через счётчик остаются игровыми. Симуляция и данные партий не меняются.

Это прототип, не полный выпуск набора. Он не установлен в обычную игру пользователя. Глобус, орбитальные объекты, другие классы юнитов и отдельные транспортные маршруты не объявлены покрытыми.

## Масштаб

Длина танка в системе координат фигурок плавно интерполируется между 24 при зуме7, 32 при зуме13 и 36 при зуме26; вне диапазона ограничивается. Проверка масштаба выполняется дважды в секунду. Геометрия существующих фигурок изменяет масштаб без повторной загрузки GLB. Экипаж смещён в сторону от корпуса. Клик по самому корпусу отдельно не добавлен.

## Ассет

`models/atlas_mbt.glb`: 13 416 треугольников, 5 материалов, 11 mesh primitives. Оси: Y вверх, нос -Z, метры. Габариты3.775×3.258×9.483м (высота включает антенны). Именованные Hull, Turret и Gun; исходник — `../../tools/build_tank_asset.py`. Пока без UV-текстур, анимации гусениц/башни и LOD. Художественный ориентир — `../../design/unit-concept-v1/`; полное соответствие концепту не заявляется.

## Проверка

Текущая игра0.14.1, Godot4.7.2, Vulkan / RTX5050 Laptop; собственный профиль Pax Universe Units QA. Совместный запуск с earth_atlas0.2.0 и pax_interface0.3.0. Финальный GPU-прогон22/22, exit0, stderr пуст. Реальная карта со свежим миром и тремя визуальными тестовыми отрядами, не сохранение пользователя. Проверены загрузка GLB, автоматическое подключение и переподключение, три масштаба, направление модели, native выбор, повторное использование моделей и восстановление renderer/texture при выключении.

Рендеры и отчёт: `../../previews/pax-units/render-final/`. Ограничения: нет теста большого количества подразделений, боевой анимации, смены мира и произвольных сторонних модов. В студийном рендере есть мелкий узор теней; это не финальное художественное освещение.

## Development

`../../tools/run-units-test.ps1 -Stage render-final` launches the native game binaries in a separate QA installation/profile. `-Validate` invokes the game's mod validator. Test fixtures are visual map records only, not simulation units. The regular player profile is never used by this test entry.
