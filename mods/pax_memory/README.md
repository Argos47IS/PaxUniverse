# Pax Memory 0.1.0 — эксперимент

Ограниченная память для штатного AI-контекста Pax Universe. Испытывается в отдельной копии игры 0.15.1 вместе с Earth Atlas и Pax Interface.

Мод запоминает подтверждённое состояние мира и отделяет его от сгенерированных ответов. Отбирает записи по области и релевантности, ограничивает добавленный контекст, сохраняет память вместе с партией и кеширует повторный отбор.

Команда F8 `memory_status` показывает подключение, число записей и размер последнего дополнительного блока. Настройка `enabled` включает адаптер памяти. Для отключения всего эксперимента выключите мод. Исследовавшиеся дополнения к общему промпту не включены в мод: они давали неоднородные результаты и находятся отдельно в `experiments/refactor/prompts`.

Для других модов:

```gdscript
var memory: Node = Pax.get_mod("pax_memory") as Node
if memory != null:
    var result: Dictionary = memory.call("remember", {
        "timestamp": game.day(), "entities": ["Земля", "имя страны"],
        "type": "event", "text": "Подтверждённое событие",
        "source": "game_event", "confidence": 1.0, "importance": 0.7,
        "tags": ["diplomacy"]
    })
```

Передавайте реальные подтверждённые данные; текст записи не выполняется как приказ. Поиск `context_for(query, entities, day, budget_chars)` возвращает текст, выбранные ID и причины отбора. Память ограничена 2048 записями. Ответ модели хранится как неподтверждённый, а не как факт.

Автоматический callback игры не передаёт запрос, поэтому сам адаптер знает область мира и игрока, но не намерение текущей команды. Мод не увеличивает лимит контекста модели, не заменяет ядро игры и не обещает точное размещение объектов на карте. Подробные результаты — в `experiments/refactor` репозитория.

Для папочной установки используйте имя папки `paxmemory` (без подчёркивания); ID внутри манифеста остаётся `pax_memory`. Не переносите QA-скрипты из `experiments` внутрь мода. На этом этапе мод предназначен для отдельного экспериментального профиля.
