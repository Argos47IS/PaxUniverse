# Pax Memory — эксперимент

Читать корневые AGENTS.md и docs/modding-notes-ru.md. Этот мод испытывается только в отдельной копии игры; не устанавливать его в рабочий пользовательский профиль без отдельного запроса.

Строгий GDScript, RU/EN локализация, собственные компоненты через PaxMod.load_resource. Без файловых классов, сетевых запросов и обхода песочницы. Память хранить в _save_state/_game_loaded. Нативный Provider и формат его ответа сохранять; не заменять игровые скрипты.

Адаптер Provider.статус_стороны нестабилен: проверять наличие и тип Callable, делегировать исходный вызов и восстанавливать только собственную обёртку. Ответ модели не является подтверждённым фактом или новым приказом. Внешние QA-инструменты находятся в experiments/refactor/tools, не в этой папке.
