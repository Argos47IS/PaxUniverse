# Pax Interface — внешние сценарии разработки

Сценарии перенесены из `mods/pax_interface/dev/` при переходе на песочницу игры. Они не входят в установочный ZIP и не запускаются модом.

Сохранённые GDScript-сценарии используют прежний внешний QA-профиль и низкоуровневые диагностические операции. Их нельзя копировать обратно в мод: текущий загрузчик запрещает такие операции. Результаты старых прогонов относятся к сборке игры, указанной в соответствующем отчёте; перенос файлов сам по себе не является новым успешным тестом.

`generate_sounds.py` — исходник генератора двух звуков интерфейса. Выводит WAV в `mods/pax_interface/sounds/` независимо от текущего рабочего каталога.
